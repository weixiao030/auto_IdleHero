# v0.4.0 桌面勇者自动远征 · 多实例版

一个助手可以同时调度本机和多个 Sandboxie 游戏实例，包括同一沙盒中的不同 PID。网页顶部切换实例后，开始、暂停、巡检和 F8/F9/F10 只控制当前选中的实例，其他实例继续独立运行。

- 每个实例独立保存配置、调度、命令、回执与日志，拒收跨实例或跨账号的回执。
- 自动重连默认关闭。先手动启动 Steam 与游戏，再启动助手；开启自动成长不会自动启动尚未运行的游戏。
- 修复沙盒内 Steam 更新后游戏路径变化造成的连接识别问题。
- 缩减快照、缓存未变化文件、减少后台网页轮询，并采用轻量 Windows 进程枚举。
- 保留装备与魔石保护、费用复核、未知结果隔离，以及强化和镶嵌中断后的装备恢复。

下载 `auto_IdleHero-v0.4.0-windows-x64.zip`，完整解压后阅读包内 Word 启动教程，运行 `桌面勇者自动远征.exe`。包内的沙盒版 EXE 内容相同，任选一个。工作台地址为 <http://127.0.0.1:17470/>。

更新前暂停所有实例，等待待结算与维护任务结束，使用旧版 EXE 的 `--stop` 正常退出助手，再替换程序。保留 `%LOCALAPPDATA%/WalletHeroesAssistant/` 中的配置和调度记录。旧版本仅支持单实例，回滚前另行保存整个助手数据目录。
